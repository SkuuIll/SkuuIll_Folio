# Revisión de las ediciones

La revisión compara la portada y el inicio de proyectos de las 14 ediciones en escritorio y en un teléfono de 390 px. Los proyectos, capturas y enlaces siguen procediendo del catálogo del portfolio; las ilustraciones de sistemas son conceptuales.

| Edición | Dirección revisada |
| --- | --- |
| Editorial | Mantiene la portada tipográfica y la presentación de casos en formato editorial. |
| Casebook | Relata los proyectos como casos y vuelve a mostrar la captura de CPAUL en despliegues con subcarpeta. |
| Systems | Explica las capas de interfaz, API y datos con un mapa identificado como conceptual. |
| Atelier | Combina una presentación centrada en el oficio con dos capturas reales y enlaces a sus casos. |
| Chromatic | Usa una composición de alto contraste y una captura del mapa táctico como pieza de proyecto. |
| Pocket | Prioriza una lectura breve y un índice directo de tres proyectos. |
| Studio | Presenta el proceso del problema al producto y recupera la captura de Vigía. |
| Skull OS | Conserva el escritorio interactivo y sus ventanas de proyectos documentados. |
| X-Ray | Recompone las capas con movimiento, selección manual y un recorrido opcional que se puede detener. |
| Museum | Mantiene la galería con capturas, fichas y navegación entre proyectos. |
| Terminal | Mantiene los comandos de navegación simulados, sin ejecutar código del sistema. |
| Canvas | Mantiene el mapa navegable de proyectos y sus tarjetas con información reversible. |
| Brutalist | Conserva la composición tipográfica de alto contraste y los módulos de proceso. |
| Story | Mantiene el recorrido por capítulos con imágenes de proyectos reales. |

Cada edición tiene además un encabezado de proyectos propio. Las siete portadas originales usan mensajes diferenciados. La animación respeta movimiento reducido, y los detalles añadidos tienen disposición móvil y contenido accesible sin depender de las animaciones.
