# Skull — Portfolio

Portafolio profesional de **Skull (SkuuIll)**, desarrollador de software freelance en Chaco, Argentina.

**Sitio:** https://skuuill.github.io/SkuuIll_Folio/

Este repositorio está dedicado **exclusivamente al sitio web del portafolio**. El README que aparece en el perfil de GitHub vive de forma independiente en [SkuuIll/SkuuIll](https://github.com/SkuuIll/SkuuIll).

## Sobre el proyecto

Construido con Astro, TypeScript, GSAP y Three.js; presenta casos de estudio de software, proyectos web y Android, automatizaciones y experimentos interactivos.

## Desarrollo local

```bash
npm ci
npm run dev
```

Para comprobar la compilación: `npm run check && npm run build`.

## Publicación

Este sitio se publica mediante GitHub Actions y GitHub Pages desde la rama `main`. En **Settings → Pages** seleccioná **GitHub Actions** como origen.

Las imágenes de proyectos privados se identifican como muestras, capturas o visualizaciones de demostración según corresponda. Se priorizan accesibilidad, respeto por `prefers-reduced-motion` y rendimiento.
